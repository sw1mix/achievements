# Достижения

Минималистичный трекер привычек: сетка «достижение × день» за неделю или месяц, статистика периода, ритм за последние 12 недель и тепловая карта года.

Без сборки и зависимостей — четыре файла (`index.html`, `styles.css`, `core.js`, `app.js`), данные хранятся в `localStorage` браузера.

## Возможности

- Два периода: неделя (Пн–Вс) и месяц; текущий день подсвечен, выходные приглушены
- Навигация стрелками на экране или клавишами ←/→, кнопка «Сегодня»
- Добавление, переименование (клик по названию) и удаление достижений
- Для каждого достижения — цвет и иконка (клик по значку слева от названия)
- Круговые диаграммы: общая за период + по каждому достижению
- Сводка: процент периода, лучший день, текущая серия
- Ритм: распределение по дням недели и итоги по неделям за 12 недель
- Год: тепловая карта по дням с навигацией по годам
- Светлая и тёмная тема, выбранный период и год запоминаются
- Экспорт/импорт данных в JSON
- Изменения в одной вкладке подхватываются другими открытыми вкладками

### Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| ←/→ | предыдущий/следующий период |
| T | вернуться к сегодняшнему дню |
| W / M | режим недели / месяца |
| Esc | закрыть настройку достижения |

## Структура

| Файл | Назначение |
| --- | --- |
| `core.js` | чистая логика: даты, агрегация статистики, миграция и валидация данных |
| `app.js` | рендер интерфейса и обработка ввода |
| `index.html`, `styles.css` | разметка и оформление |
| `tests/core.test.js` | тесты логики на `node:test` |

Логика намеренно отделена от DOM: `core.js` не обращается к документу и подключается
как в браузере (`window.AchievementsCore`), так и в тестах через `require`.

## Локальный запуск

Достаточно открыть `index.html` в браузере. Либо поднять локальный сервер:

```bash
python3 -m http.server 8000
```

## Тесты

```bash
npm test          # или: node --test tests/
```

Требуется Node.js 18+ (используется встроенный тест-раннер, зависимостей нет).

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и запушьте содержимое этой папки:

```bash
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

Workflow `.github/workflows/deploy.yml` прогоняет тесты и публикует сайт при каждом пуше в `main`;
`ci.yml` прогоняет тесты в merge/pull request. Адрес будет `https://<логин>.github.io/<репозиторий>/`.

## Данные

Всё хранится локально в браузере под ключом `achievements.v1`, на сервер ничего не уходит.
Чтобы перенести историю на другое устройство, используйте «Экспорт» и «Импорт».

При загрузке данные проходят через миграцию: файлы прежних версий дочитываются без потерь,
а повреждённые записи (неизвестные привычки, некорректные даты) отбрасываются.
